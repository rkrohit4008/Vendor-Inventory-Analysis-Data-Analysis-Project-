# Vendor Sales Analysis Project

## Project Overview
This project focuses on analyzing vendor and inventory data to identify profitable vendors and understand sales performance.

## Data Source
- Raw data collected in CSV format
- Data stored and managed using SQLite database
## Due to file size limitations, the complete dataset is hosted externally.
Full Dataset: https://drive.google.com/drive/folders/1KFOOgofj6THoQPb2I1VVhOqRjIWS55GO?usp=sharing

## Tools & Technologies
- Python (Pandas, NumPy)
- SQL (SQLite)
- Matplotlib & Seaborn (Visualization)

## Process
1. Loaded raw CSV files
2. Ingested data into SQLite database
3. Performed data cleaning and transformation
4. Conducted exploratory data analysis (EDA)
5. Created vendor sales summary
6. Applied statistical analysis (T-test)

## Key Analysis
- Vendor performance comparison
- Profitability analysis
- Sales trends
- Statistical testing between vendor groups

## Results
- Identified top-performing vendors
- Compared high vs low vendors using statistical methods
- Generated insights for better vendor selection

## Project Structure
- data/ → Raw CSV files
- notebooks/ → Analysis notebooks (P1, P2, P3)
- database/ → SQLite database file
- images/ → Graphs & visualizations

## Conclusion
This project helps in understanding vendor performance and supports decision-making for selecting profitable vendors.
